# مبارزة الأرقام

## العب الآن

[افتح اللعبة على GitHub Pages](https://o7aso1.github.io/number-duel/)

لعبة تخمين أرقام عربية تعمل في المتصفح، ضد الكمبيوتر أو بين لاعبين. يختار كل لاعب رقماً سرياً من 3–6 خانات، ثم يتناوب اللاعبان على التخمين مع معرفة عدد الخانات الصحيحة في أماكنها.

تتضمن النسخة الحالية أربعة أنماط، وقواعد اختيارية لتكرار الأرقام، ومحاولات محدودة، ونظام نقاط، وسجلًا لتقلص الاحتمالات، وملاحظات يدوية، وثلاثة أنواع من التلميحات.

أضيفت أيضًا لعبة ذاكرة الأرقام وتحدٍ يومي موحد، وملفات شخصية بصور رمزية ومستويات وخبرة وإنجازات وإحصائيات. تدعم المبارزة لاعب كمبيوتر بثلاث درجات، واللعب المحلي على جهاز واحد، وإعادة المباراة ومشاركة النتيجة بصورة. تشمل الواجهة أصواتًا اختيارية واهتزازًا خفيفًا وإيماءات سحب للجوال، وأربعة ثيمات تُفتح مع التقدم: كلاسيكي ونيون وفضائي وورقي.

بيانات الملف الشخصي والتقدم والإحصائيات تحفظ محليًا في المتصفح حاليًا. الغرف الخاصة تسمح لمنشئ الغرفة باختيار النمط وعدد الخانات وقاعدة التكرار، ثم تُفرض القواعد نفسها على الطرفين من الخادم.

يمكن أن يحتوي الرقم السري على رقم واحد مكرر بالكامل مثل `1111`. لا يسمح بإدخال `1111` كتخمين مباشر؛ يصل اللاعب إليه بالاستنتاج من تخمينات متنوعة.

## إعداد Supabase

شغّل الملفات التالية بالترتيب في SQL Editor لمشروع Supabase:

1. `supabase-setup.sql`
2. `supabase-patch-v3.sql`
3. `supabase-patch-v4.sql`
4. `supabase-patch-v5.sql`
5. `supabase-patch-v6.sql`

الترقيتان الخامسة والسادسة مطلوبتان قبل تجربة اللعب الجماعي بالواجهة الحالية. الخامسة تؤمّن الجلسات، والسادسة توحّد إعدادات الأنماط والمحاولات والتلميحات والنقاط بين اللاعبين.

الترقية الخامسة:

- تضيف مفتاح جلسة سرياً مستقلاً لكل لاعب وتخزن بصمته فقط.
- تمنع القراءة المباشرة لجداول الغرف والأسرار والدردشة.
- تجعل اللعب العشوائي عملية ذرية داخل قاعدة البيانات.
- تفرض مؤقت الدور من الخادم.
- تضيف حدوداً لإنشاء الغرف والانضمام وإرسال الرسائل.
- تنظف الغرف القديمة أثناء إنشاء غرف جديدة.

الترقية السادسة:

- توسّع عدد الخانات إلى 6.
- تضيف قواعد تكرار الأرقام وأنماط عادي وسريع وخبير ومحاولة واحدة.
- تفرض عدد المحاولات والتلميحات من الخادم.
- تحسب نقاط الفائز وتعيدها ضمن حالة الغرفة.
- تضيف تلميحات الموضع، والزوجي أو الفردي، والاستبعاد الذكي.

لا تُعد مفاتيح اللاعبين أو `nd_active` بيانات حساب دائمة؛ تحفظ محلياً فقط لاستعادة المباراة بعد تحديث الصفحة.

## البناء والنشر

```bash
npm run build
npm run build:pages
```

ينتج `build:pages` نسخة GitHub Pages داخل `docs/`. إعداد Pages في المستودع يجب أن ينشر مجلد `/docs` من فرع `master`.
